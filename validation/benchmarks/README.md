# 文献基准与实验数据（v3）

本目录整理了用于检验 Dmitte 氚迁移模型的公开实验数据。v2 版逐条对照**全文**核实了 v1 中仅来自摘要的数值；
v3 版补读了 5 篇原文，改正了 v2 的错误，给每条基准加上实验元数据，并加入情景卡和冻结的校准/测试划分（第 0 节）。

```
benchmarks/
├── literature_benchmarks.csv   # 标量基准：65 条，每条带 low/central/high、单位、对应的模型指标、出处表格和实验元数据
├── sources.csv                 # 文献登记：引用、链接、获取方式（全文/摘要）
├── scenario_cards.csv          # 情景卡：15 组实验的暴露条件、强迫数据完整程度和缺失项
├── split.csv                   # 校准集 / 测试集划分（测试集已冻结）
└── datasets/                   # 逐次实验数据（19 个 CSV，按原表转录，每行注明 source_id 和表号）
```

## 0 v3 的结构

**元数据列**（`literature_benchmarks.csv` 最后 5 列）：

| 列 | 取值 | 用途 |
|---|---|---|
| `setting` | chamber（实验室舱室，强制通风）、field box（田间或盆栽外的通风箱）、greenhouse、field（田间慢性）、lab、review | 舱室和箱体通风使叶–气速率比田间偏高，只能作田间的一阶近似（TECDOC-1738 §7.9） |
| `tracer` | HTO、D2O、HT、14CO2 | D₂O 和 ¹⁴C 只是替代示踪剂 |
| `exposure_h` | 1、2、8、chronic 等 | 虚拟实验按同样时长暴露 |
| `photosynthesis` | C3、C4 | 玉米是 C4，不能代替马铃薯和小麦（C3） |
| `kind` | measured（实测）、derived（由实测拟合的速率常数）、compilation（多项研究汇总）、parameter（文献模型参数） | 区分实验事实和模型参数 |

**情景卡**（`scenario_cards.csv`）：每组实验一行，列出暴露时长、开始时刻、生育期、温度、湿度、光照、空气 HTO、是否排除根系吸收、
暴露后的处理，以及 `forcing_status`：complete（可直接用实测条件驱动模型）、partial（缺部分条件，只能比较比值）、insufficient。
目前 complete 的只有小麦舱室逐时实验（白天弱光、夜间各一组，Diabaté & Strack 1997 表 2–3）。

**校准/测试划分**（`split.csv`）：按实验活动整体划分，同一组实验不拆开。测试集 15 条：

| 测试组 | 基准 | 数据集 | 理由 |
|---|---|---|---|
| FZK 小麦舱室实验（Diabaté & Strack 1997） | B46–B48、B51–B55 | `wheat_DE_chamber_1993.csv`、`wheat_DE_chamber_timeseries_1993.csv` | 从未参与模型对比；有完整逐时强迫 |
| FZK 马铃薯/菜豆舱室实验（TECDOC-1738 表 24） | B12、B24、B25 | `potato_bean_DE_chamber.csv` | 唯一的马铃薯氚实验；B12 在 v1–v2 报告中出现过（已知泄漏） |
| Pickering 慢性释放（EMRAS TC14 表 3.7） | B34–B37 | `pickering_chronic_ratios.csv` | 从未参与模型对比 |

测试集的 sha256 指纹记录在 `../analyze.py`（`FROZEN_TEST_FINGERPRINT`），`tests/test_smoke.py` 会在测试集被改动时报错。
测试集已于 2026-10-29 用模型 commit `4e09ac5` 运行一次，结果见 `../README.md` 第 4.6 节。
模型修改全部完成后，才用 `python validation/analyze.py --include-test` 运行一次。

另需注意的口径差异：
- **暴露时长**：马铃薯和菜豆是 2 h、小麦舱室 2 h、田间箱 1 h、水稻有 1/4/8 h，TLI 和吸收比都随时长增加（表 36）。用模型对比时应按原实验时长设定暴露。
- **示踪剂**：日本的水稻、大豆、柑橘实验用 D₂O，马铃薯情景用 ¹⁴CO₂，都只能作替代基准。
- **慢性基准互相矛盾**：块茎 OBT/空气，Chalk River 菜园为 0.93（B18），Pickering 块根为 0.30（B34）。前者按灌浆期 15–20 d 的空气浓度归一化，后者按采样前 2 个月均值归一化；文献整体上 OBT/HTO 比值在 0.5–20 之间。
- **CNL 数据**是在烟羽经过后几小时采样的，OBT 偏高，不适合作为稳态基准（TECDOC-1991 5.3.1.2 节）。
