# 文献基准与实验数据（v2）

本目录整理了用于检验 Dmitte 氚迁移模型的公开实验数据。v2 版在放开 IAEA、arXiv、OSTI 的网络访问后，
逐条对照**全文**核实了 v1 中仅来自摘要的数值，并从全文中补充了大量逐次实验数据。

```
benchmarks/
├── literature_benchmarks.csv   # 标量基准：46 条，每条带 low/central/high、单位、对应的模型指标、出处表格
├── sources.csv                 # 文献登记：引用、链接、获取方式（全文/摘要）
└── datasets/                   # 逐次实验数据（17 个 CSV，按原表转录，每行注明 source_id 和表号）
```

另需注意的口径差异：
- **暴露时长**：马铃薯和菜豆是 2 h、白菜 4 h、水稻有 1/4/8 h，TLI 和吸收比都随时长增加（表 36）。用模型对比时应按原实验时长设定暴露。
- **示踪剂**：日本的水稻、大豆、柑橘实验用 D₂O，马铃薯情景用 ¹⁴CO₂，都只能作替代基准。
- **慢性基准互相矛盾**：块茎 OBT/空气，Chalk River 菜园为 0.93（B18），Pickering 块根为 0.30（B34）。前者按灌浆期 15–20 d 的空气浓度归一化，后者按采样前 2 个月均值归一化；文献整体上 OBT/HTO 比值在 0.5–20 之间。
- **CNL 数据**是在烟羽经过后几小时采样的，OBT 偏高，不适合作为稳态基准（TECDOC-1991 5.3.1.2 节）。

## 6 对上一轮验证结论的影响

> 更新：`../results/` 现已用 v2 基准、在第一步修正后的代码上重新运行，结果见 [../README.md](../README.md) 第 4 节。
> 下面是重新运行前根据 v1 输出做的预期，保留作记录。

`../results/` 中的对比结果当时是用 **v1 基准**算的，没有重新运行。
根据上一轮已有的模型输出，可以预期以下判定会变化：
- **B5 白天交换速率**：基准从"< 1 h⁻¹"改为 0.85–1.66 h⁻¹ 后，baomi 马铃薯（1.2 h⁻¹）会变为"符合"，UFOTRI（0.35）和 default（0.012）会变为偏低。
- **B6 昼夜比**：基准收紧到 3–5 后，UFOTRI 常数版（比值为 1）的偏离会更明显。
- **B1、B2 叶片吸收**：马铃薯现在有直接基准（B24 白天 83 %、B25 夜间 14 %，2 h 暴露），比用白菜/水稻代替更贴切；上一轮马铃薯的 1–7 % 仍明显偏低。
- **B12 马铃薯 TLI** 数值未变，但已核实为 2 h 暴露；换算到 1 h 暴露时文献值应更低，所以上一轮"模型偏高"的结论会更强。
- **慢性块茎 OBT/空气**：增加了 Pickering 块根 0.30±0.09（B34），与 Chalk River 菜园的 0.93（B18）相差约 3 倍。UFOTRI 的 1.15 接近后者、比前者高约 4 倍，需要两者都报告。

建议下一步：
1. 用 `run_validation.py` 按原实验时长（马铃薯 2 h、白菜 4 h）重新做虚拟实验；
2. 增加大豆 SB1/SB4 时间序列的逐点对比（需在 WOFOST 中配置大豆）；
3. 增加 Pickering 慢性情景对比（需在 `analyze.py` 的 `CHECKS` 中加入 B34–B36）。
